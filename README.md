### 🏪 بازار ایرانی - سیستم فروشگاه کاملا فارسی (جدید 3.0):

**دستور**: `/bazaar` یا `/بازار`

**واحد پول**: سکه دریک هخامنشی (`GOLD_NUGGET`) - اولین سکه جهان، ساخته داریوش بزرگ

**4 راسته بازار**:
- **⚔ راسته شمشیرگرها**: شمشیر الموت (20 سکه)، شمشیر بابک (18)، آکیناکه (30)، کمان آرش (25)
- **💎 راسته زرگرها**: تاج کوروش (50)، مروارید خلیج فارس (15)، آتش مقدس (20)
- **🧶 راسته فرش‌فروشان**: فرش کرمانی (10)، پر سیمرغ (12)
- **☕ راسته عطاران**: چای لاهیجان (5)، منشور کوروش (30)، خشت ایلامی (8)

**نحوه بدست آوردن سکه**: از چست دانجن‌ها، کشتن باس‌ها، معامله با روستاییان

**GUI کاملا فارسی** با شیشه تزئینی و دکمه بازگشت

### 🏘️ روستاهای ایرانی (جدید 3.0):

- تبدیل خودکار روستاهای وانیلا به ایرانی وقتی چانک لود می‌شود
- نام‌های فارسی: `حاج کریم - کدخدا، مشهدی حسن - کشاورز، فاطمه خانم - قالیباف`
- نام روستا: `روستای کندوان - آذربایجان، میمند - کرمان 3000 ساله، ابیانه - اصفهان سرخ`
- معماری: خانه کاهگلی، مسجد با گنبد فیروزه‌ای، چاه آب

## 🎮 دستورات کاملا فارسی 3.0:

```
/race choose - انتخاب نژاد ایرانی
/race info - اطلاعات نژاد

/dungeon list - لیست 16 دانجن تاریخی ایران
/dungeon generate <ID> - ساخت دانجن
  /dungeon generate ALAMUT_CASTLE
  /dungeon generate PASARGAD_TOMB
  /dungeon generate TAKHT_JAMSHID_SKY
/dungeon teleport - تلپورت به دانجن
/dungeon bazaar - ساخت بازار ایرانی
/dungeon caravanserai - کاروانسرا
/dungeon chaikhaneh - چایخانه
/dungeon abanbar - آب‌انبار

/bazaar - باز کردن بازار ایرانی (GUI)
/bazaar build bazaar - ساخت بازار
/bazaar build village - ساخت روستای ایرانی
/bazar - مترادف
/بازار - مترادف فارسی

/hardcore reload - ریلود کانفیگ فارسی
```

## ⚙️ کانفیگ فارسی 3.0:

```yaml
dungeons:
  enabled: true
  spawn-chance: 0.006 # 0.6% هر چانک
  all-biomes-covered: true # هر بایوم یک دانجن

structures:
  spawn-chance: 0.012 # 1.2%

bazaar:
  currency: GOLD_NUGGET # سکه دریک
  currency-name: "سکه دریک هخامنشی"

villages:
  enabled: true
  transform-vanilla: true
```
