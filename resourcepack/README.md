## Installation:
1. Download pack from GitHub releases or repo:
   `https://github.com/amirragaby110-glitch/plugin-1.12.2-minecraft-iranian/raw/main/resourcepack/IranianHardcore-ResourcePack.zip`
2. Gharar dadan dar poosheye `resourcepacks` ya faalsazi dar `config.yml`:
```yaml

  enabled: true
  auto-send-on-join: true
  url: "https://github.com/amirragaby110-glitch/plugin-1.12.2-minecraft-iranian/raw/main/resourcepack/IranianHardcore-ResourcePack.zip"
```
