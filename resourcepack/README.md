# Iranian Hardcore Resource Pack v4.0 - Finglish

Resource Pack makhsus baraye plugin Iranian Hardcore v4.0

## Features:
- Custom textures for 7 Iranian mobs:
  - Div Sepid (White Demon) - Snow biome
  - Div Siah (Black Demon) - Desert
  - Simurgh - Legendary bird, Alborz mountains
  - Zahhak - 3-headed dragon king
  - Rostam Ghost - Hero spirit
  - Al - Swamp witch
  - Kaveh - Blacksmith hero (friendly)

- Custom items:
  - Mashk Ab - Iranian water skin
  - Derik coin - Achaemenid coin
  - Persian items

## Installation:
1. Download pack from GitHub releases or repo
2. Put in resourcepacks folder or let plugin auto-send if enabled in config.yml:
```yaml
resourcepack:
  enabled: true
  auto-send-on-join: true
  url: "https://github.com/amirragaby110-glitch/plugin-1.12.2-minecraft-iranian/raw/main/resourcepack.zip"
```

## For Server Owners (Aternos):
- Upload resourcepack.zip to a file host (Dropbox, GitHub, etc)
- Set URL in config.yml
- Players will be asked to accept resource pack on join

## Compatibility:
- Minecraft 1.12.2
- Spigot/Paper 1.12.2
- Aternos compatible

## Notes:
- Current version uses vanilla entity textures with custom names/effects
- Future versions will include actual custom textures (requires Optifine or custom server)
